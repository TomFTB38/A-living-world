# A Living World — recettes.
# Groupes : un nom, un libellé, les objets qui en font partie.
#   groupe <id> | <libellé> | objet objet …
# Recettes : une par ligne.
#   <sortie> <quantité> | <atelier> | <ingrédient> <n>, … | <catégorie>
#   Atelier : main, etabli, feu, four, enclume, taille.
#   Un ingrédient précédé de « ! » est un outil nécessaire mais conservé (le couteau, l'aiguille, le marteau).
# Une recette apparaît dans le livre dès qu'on a eu en main l'un de ses ingrédients.
